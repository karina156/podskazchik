# Подсказчик

Дизайн-фикция для курса «Дизайн интерактивных систем», модуль 2.

Линзы подсказывают фразу, которую ждёт собеседник. Платите своими словами: подсказанная фраза навсегда заменяет вашу. Линз не существует.

На странице есть интерактивный разговор из трёх сцен, выписка о замене формулировок и честный отказ «Не надевать». Введённые фразы никуда не отправляются.
